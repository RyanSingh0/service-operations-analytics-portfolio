How to interpret this forecast

  • Target: recorded requests created per calendar date, using the source's New York local timestamps. Only aggregate counts are downloaded; addresses and request descriptions are not used.
  • Models: last available matching weekday, mean of four matching weekdays, and regularized seasonal regression using past demand and calendar features. Regression must improve validation MAE by at least 2% to replace the better baseline.
  • Error bands use a separate 42-day calibration period. Nominal 90% coverage is an empirical target, not a guarantee. The observed test coverage is shown above.
  • Current source records can be corrected retrospectively. Backtests use the current extract, not archived historical publication vintages. Past data-publication delays are not reconstructed.
  • Borough and city forecasts are fitted separately and need not add up. City totals include requests with unknown borough. Requests do not measure all community needs or service quality.
  • Unexpected events, reporting changes, holidays, and weather can shift demand. No causal or operational-performance claims are made.
